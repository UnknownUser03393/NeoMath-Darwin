# 答辩问答

**为什么不用纯 Python？**  
数学真值、语义比较和未来可复用能力集中在独立 C++20 MathCore；Python 只做桌面编排。

**AI 会不会算错？**  
AI 不产生解集、定义域或 Verified 状态。它只生成白名单 Intent 或改写诊断，候选变换必须
由 C++ 执行并通过证书验证。

**Probe 为什么可信？**  
Probe 来自前后解集或定义域的精确差集，并分别代回两棵 AST；不是随机抽样。

**为什么不支持所有数学？**  
首版刻意限定单变量实数代数。不能证明时返回 Unverified，绝不把启发式结果包装成 Verified。

**如何独立验证？**  
Catch2/pytest 覆盖固定语义，SymPy 接收 C++ 输出的结构化 AST 做差分，随机测试使用固定 Seed。
